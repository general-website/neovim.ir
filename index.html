Plugin های محبوب

ابزارهای ضروری جامعه Neovim را کشف کن.

مشاهده همه

vim-fugitive

★ 21,000

رابط قدرتمند Git داخل Vim/Neovim.

lazy.nvim

★ 17,000

مدیر بسته مدرن Neovim با lazy-loading و UI قدرتمند.

telescope.nvim

★ 16,000

Fuzzy finder قدرتمند برای فایل ها، Buffer ها، LSP و بیشتر.

nvim-lspconfig

★ 11,000

پیکربندی آماده برای Language Server Protocol.

nvim-treesitter

★ 11,000

Highlight، Indent و Text Objects مبتنی بر Treesitter.

nvim-cmp

★ 9,200

موتور تکمیل خودکار قابل توسعه برای Neovim.

Theme های محبوب

ظاهر ادیتور را با Theme های منتخب تنظیم کن.

مشاهده همه

tokyonight.nvim

Theme تاریک محبوب با پالت آبی و بنفش الهام گرفته از شهر توکیو.

catppuccin

پالت نرم و چشم نواز با طعم های Latte، Mocha و بیشتر.

gruvbox.nvim

پالت گرم و کلاسیک Gruvbox برای Neovim.

onedark.nvim

الهام گرفته از One Dark با پشتیبانی از چند سبک.
